MPEG-DASH through the HLS player

This sample loads a static MPD and bridges its fragmented MP4 segments to the existing Omakase HLS playback engine.

Initializing player...

The default manifest uses two video renditions from Envivio's public DASH test stream, without audio so it also works in browsers without AAC support. Loading does not autoplay; press Play after it is ready.

For audio/video playback in a browser with AAC support, load https://dash.akamaized.net/envivio/EnvivioDash3/manifest.mpd.

Use one static MPD with compatible, contiguous Periods and fragmented MP4 using SegmentTemplate, SegmentList or SegmentBase/SIDX addressing. Pre-authored ad Periods are supported. HTTP byte-range support is recommended; full-file HTTP 200 responses are streamed without buffering the whole file unless it is addressed as one segment, but may require downloading the prefix again for each fragment. MPD WebVTT, TTML/IMSC and MP4 wvtt/stpp subtitles and individual/tiled image thumbnail tracks are supported. Live, DRM, in-video CEA captions and trick-mode representations are not supported. Streams must allow CORS.
